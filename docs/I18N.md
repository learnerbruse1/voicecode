# Internationalization Guide

VoiceCode supports English (`en`), Simplified Chinese (`zh`), and Japanese (`ja`) in the desktop UI. The default UI language is English.

## User-facing behavior

- Open **Settings -> Language** to choose the interface language.
- The same module also controls the default transcription language sent to Whisper.
- Language changes are applied immediately to static labels, current page title/subtitle, status text, dynamic settings descriptions, dependency cards, extension cards, and accessibility labels.
- The app sets `html lang` and `html[data-ui-language]` so CSS can adjust label width, top bar spacing, and wrapping for each supported language.

## Source files

| File | Responsibility |
| --- | --- |
| `static/index.html` | Markup and `data-i18n` / `data-i18n-title` / `data-i18n-aria` hooks |
| `static/js/i18n.js` | Translation catalogs |
| `static/js/dom.js` | Applies translations and language attributes |
| `static/js/settings.js` | Saves `ui_language` and refreshes language-sensitive panels |
| `static/css/app.css` | Responsive and language-specific layout rules |
| `src/voicecode/settings.py` | Validates `ui_language` and persists defaults |

The packaged static copy under `src/voicecode/static/` must stay byte-for-byte synchronized with `static/`. The test suite enforces this.

## Adding or updating copy

1. Add the English key first in `static/js/i18n.js`.
2. Add equivalent `zh` and `ja` entries in the same file. Non-English catalogs must include every English key.
3. Use `data-i18n` for text content, `data-i18n-title` for `title`, `data-i18n-aria` for `aria-label`, and `data-i18n-placeholder` for placeholders.
4. If translated labels are longer, add CSS under `html[data-ui-language="<code>"]` rather than hard-coding inline styles.
5. Mirror changed static files into `src/voicecode/static/`.
6. Run frontend syntax checks and the Python test suite.

## Quality checklist

- No visible UI string should be hard-coded unless it is a brand name, model name, unit, or user/device data.
- Text must be allowed to wrap; avoid fixed-height containers for translated content.
- Buttons and navigation items should support longer Japanese strings without clipping.
- Keep backend errors and logs in English for diagnostics, but expose actionable UI guidance through translated frontend strings.
